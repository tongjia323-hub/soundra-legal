# 烟账隐私政策

状态：正式发布。

最后更新：2026-05-26

## 中文

烟账是一款本地处理型工具，核心功能在用户设备本机完成。

### 我们收集的数据

V1.0 默认不收集、上传或共享用户个人信息。

用户在 App 内输入或生成的数据包括：

- 一包价格
- 每包支数
- 起始日常量
- 每日小目标
- 今日或昨日记录
- 实际点着根数
- 目标名称和目标金额
- 按钮声音和提醒设置

这些数据用于在用户设备本机计算烟草使用成本、避免支出金额、账本统计和提醒。

### 数据存储

上述数据保存在用户设备本机。V1.0 不提供账号系统、云同步、云存储或用户内容上传。

### 通知

如果用户允许通知，烟账会使用本地通知提醒用户：

- 3 分钟后回来确认结果
- 晚间补一下今天

通知仅在用户设备本机触发，不需要远程推送。

### 第三方服务

V1.0 默认不接入分析 SDK、广告 SDK、社交 SDK 或第三方登录。

### 儿童隐私

烟账面向成年用户，不面向儿童设计。

### 联系方式

技术支持联系方式：tongjia323@gmail.com。

## English

Yanzhang is a local processing utility. Its core functions are completed on the user's device.

### Data We Collect

Version 1.0 does not collect, upload, or share personal information by default.

Data entered or created in the app may include:

- Pack price
- Cigarettes per pack
- Starting daily baseline
- Daily goal
- Today or yesterday records
- Actual cigarettes lit
- Goal name and target amount
- Button sound and reminder settings

This data is used locally on the user's device to calculate tobacco use cost, avoided spending, ledger statistics, and reminders.

### Data Storage

The data above is stored locally on the user's device. Version 1.0 does not provide accounts, cloud sync, cloud storage, or user content upload.

### Notifications

If the user allows notifications, Yanzhang uses local notifications to remind the user to:

- Return after 3 minutes and confirm the result
- Calibrate today's record in the evening

Notifications are triggered locally on the user's device and do not require remote push notifications.

### Third-Party Services

Version 1.0 does not include analytics SDKs, advertising SDKs, social SDKs, or third-party login by default.

### Children's Privacy

Yanzhang is intended for adult users and is not designed for children.
