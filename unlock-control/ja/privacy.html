01 · 適用範囲

本方針は Unlock Control の現在のローカル Web プレビューと iPhone / iPad ネイティブ開発検証版に適用されます。機能は使用する版によって異なり、未実装の家族間同期、クラウド認識、購入機能は対象外です。

保護者がタスクを設定し、オンラインアカウントは現在不要です。Web の役割切替は開発確認用で、安全な保護者認証ではありません。正式公開前に保護者アクセスの分離が必要です。

03 · 使用と共有

現在のコードはタスク情報を開発者のサーバーへ送信しません。家族間の遠隔同期、広告会社、データ仲介業者、第三者分析基盤への共有はありません。子どもの情報を販売しません。

端末内でも個人情報を扱います。呼び名や課題、自由入力に個人を特定する内容が含まれる場合があります。ニックネームを使い、必要な内容のみを保存してください。

04 · 権限とファイル

ネイティブ版は Apple の Family Controls、Managed Settings、Device Activity で保護者の承認と選択対象の管理を要求します。不透明トークンを使用し、完全な閲覧履歴や連絡先を読み取らず、正確な位置情報を要求しません。システム処理は Apple の規則に従い、実際の制御は承認と版によります。

Web の資料追加は、選択したファイルを端末内ブラウザに保存する操作です。サーバーへのアップロードではありません。自分の iCloud 等から選ぶ場合、ダウンロードはそのサービスと利用者の操作に従います。選択を断っても他のファイルは取り込みません。

05 · 音読・運動・楽器練習

現在の版はカメラやマイクで子どもを記録せず、顔認識、縄跳び自動計数、音読認識、演奏品質採点を行いません。保護者が選んだ既存の音声・動画は対応する Web 画面で端末内再生できますが、背景録音とは異なります。

これらのタスクは保護者の条件に沿って提出し、保護者が確認します。録音、撮影、AI 認識、クラウド処理を追加する前に、情報、目的、受領者、保存期間、削除方法を説明し、方針を更新して適切な承認を取得します。

06 · 保存期間とバックアップ

設定、記録、資料は該当する保存領域を消去するまで保持します。タスク単位または期限による自動削除はありません。報酬の失効は記録の削除ではありません。ネイティブの書込には iOS のファイル保護を使い、Web の保護はブラウザと端末の安全性に依存します。

開発者のクラウドバックアップはありません。Apple の端末バックアップ、iCloud、システム診断、ブラウザのバックアップが設定によりコピーを保存する場合があります。ネイティブ情報はシステムバックアップから明示的に除外していません。バックアップ、原本、書き出したコピーは別に管理してください。

07 · 閲覧・書出し・削除・承認撤回

利用する版のタスク、履歴、設定で情報を確認できます。Web の書出しには正解を含み、添付ファイルの原本を含みません。ネイティブ版の完全な書出しや個別削除は未実装です。

Web はブラウザ設定で該当サイトのデータを消去すると記録と資料が削除され、当方で復元できません。ネイティブは iOS / iPadOS の「Appを削除」で現在のインストールのデータを消去します。「Appを取り除く」は書類やデータを保持する場合があります。バックアップは別に管理します。

保護者はシステムのスクリーンタイム／家族管理設定で撤回可能な承認を管理・撤回できます。手順は OS と承認方式によって異なります。権限撤回と記録削除は別操作です。端末だけにある情報を当方が遠隔で読取・変更・削除することはできません。

08 · 子どもと保護者

家族のタスクと内容は保護者が決定します。現在、子どもの本名、身分証、メール、電話番号、正確な位置情報は要求しません。子どもの公開プロフィール、公開投稿、知らない人とのチャットはありません。

子どもに関する相談は保護者が行ってください。必要性と適切な承認がなければ顔、声、学校、住所、課題全文を送らないでください。誤送信した情報は保護者が運営者へ相談できます。

09 · サポートへの連絡

自らメールを送る場合、メールアドレス、相談内容、選択した添付資料を受領し、回答、調査、関連する法的義務にのみ使用します。問題や子どもの資料は自動添付しません。

相談の処理、必要な追加連絡、適用される法的義務に必要な期間のみ保管します。下記メールへ、当方が保有するサポート資料の閲覧、訂正、削除を依頼できます。メールは Gmail が提供し、Google のプライバシーポリシーに従います。端末内情報を遠隔削除することはできません。

10 · 本ポリシーの Web サイト

本方針とサポートのページは GitHub Pages で公開します。当方の広告、分析スクリプト、追跡ピクセル、外部フォント、タスクデータベース接続はありません。GitHub は安全対策のため訪問者の IP アドレスを記録・保存します。ネットワーク情報の処理と保管は GitHub の方針に従い、当方はログの固定削除期限を約束しません。

閲覧によりアプリ内の問題、正解、子どもの資料はアップロードされません。自らメールを送る行為は別です。第三者サービスの処理と地域間移転の可能性については下記の公式方針をご覧ください。
