지원 연락

자주 묻는 질문

파일이 서버로 전송되나요?

현재 과제와 첨부를 자동 업로드하지 않습니다. 웹 가져오기는 기기 브라우저에 저장합니다. 수동 내보내기, 이메일, 백업은 사용자 또는 시스템에 따릅니다.

40분 연습하면 자동 점수가 나오나요?

연습 타이머를 사용하는 악기 과제의 경우 네이티브 개발 버전은 악기, 곡, 구간 또는 마디, 목표 시간, 반복 횟수, 템포(BPM), 작성한 조건과 누적 연습 시간을 기기에 저장합니다. 연습 화면이 전면에 있고 타이머가 실행 중일 때만 누적합니다. 화면을 벗어나거나 기기를 잠그거나 백그라운드로 이동하면 일시 정지하며 저장된 누적 시간은 기기에 남습니다. 다시 시작해도 자리를 비운 시간은 추가하지 않습니다. 보호자가 재시도를 요청하면 해당 과제의 연습 시간은 0부터 다시 시작합니다. 이 기록은 실제 연주를 증명하지 않습니다. 연주, 반복 횟수, 템포와 완료 여부는 보호자가 확인합니다. 앱은 마이크를 사용하거나 녹음하지 않으며 낭독 또는 연주를 자동 평가하지 않습니다. 운동 화면은 사용자가 카메라를 시작한 후에만 처리합니다. 개발 로직은 스쿼트, 팔굽혀펴기, 윗몸 일으키기를 지원하지만 정확도는 검증 전입니다. 자세 평가, 얼굴 또는 신원 인식, 줄이 통과했는지 증명하지 않습니다. 화면은 기기에서 잠시 처리하며 녹화, 저장, 업로드하지 않습니다. 관절 위치와 횟수로 실시간 안내하며 제출한 추정 횟수는 로컬 과제 기록에 저장할 수 있고 부모 확인이 필요합니다. 일시 정지, 화면 종료 또는 앱이 백그라운드로 전환되면 카메라가 멈춥니다.

사본을 보관하려면?

웹 설정에서 기록을 내보낼 수 있습니다. 정답은 포함하고 첨부 원본은 제외합니다. 네이티브 전체 내보내기는 미구현입니다. 원본은 따로 보관하세요.

어떻게 삭제하나요?

웹: 사이트 데이터를 지우면 로컬 기록, 첨부 파일, PIN 정보가 삭제되며 앱에서 복구할 수 없습니다. 네이티브: “앱 삭제”는 설치된 앱 데이터를 제거하고 “앱 정리하기”는 데이터를 남길 수 있습니다. 어느 쪽도 키체인 자격 정보 재설정을 보장하지 않습니다. 현재 PIN 재설정 또는 자격 정보 전체 삭제 기능이 없습니다. 백업, 원본, 수동 내보내기 사본은 별도로 관리하세요.

보호자와 아이의 자료는 안전한가요?

실제 로컬 데이터를 사용하는 버전은 6자리 PIN으로 보호자 작업을 보호합니다. 세션 만료, 백그라운드 이동, 아이의 과제 시작 후에는 재인증이 필요합니다. 기기 암호나 Apple 가족 승인을 대신하지 않습니다. 가상 웹 데모는 PIN을 생략합니다. 기기에 접근할 수 있는 사람은 브라우저 저장소를 확인하거나 지울 수 있습니다.

보호자 PIN을 잊었습니다. 지원팀이 재설정할 수 있나요?

아니요. 현재 온라인 계정이나 PIN 복구·재설정 기능이 없습니다. 지원팀은 로컬 PIN을 알아내거나 원격으로 재설정할 수 없습니다. 재설치해도 키체인 정보가 남을 수 있습니다. 웹 사이트 데이터를 지우면 미리보기의 PIN과 로컬 기록이 함께 삭제되며 저희는 복구할 수 없습니다.
