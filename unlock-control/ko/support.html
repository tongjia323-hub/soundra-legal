지원 연락

자주 묻는 질문

파일이 서버로 전송되나요?

과제나 첨부 자료가 개발자 서버로 자동 전송되지 않습니다. 자료는 이 기기에 남습니다. Apple 구입, 시스템 백업, 외부 파일 제공업체, 직접 보내기로 선택한 이메일은 별도의 처리 과정이며 개인정보처리방침에 설명되어 있습니다.

40분 연습하면 자동 점수가 나오나요?

아니요. 앱은 포그라운드에서의 연습 시간을 기록하며, 실제 연주의 증거나 음악 점수를 기록하는 것이 아닙니다. 연주, 반복 횟수, 템포, 완료 여부는 보호자가 확인합니다. 마이크 녹음이나 음악·낭독 자동 평가는 없습니다. 운동 횟수도 보호자가 확인해야 하는 추정치입니다.

사본을 보관하려면?

버전 1.0에는 앱 전체 내보내기 기능이 없습니다. 원본 학습지, 악보, 파일은 따로 보관하고 기기 백업은 시스템 설정에서 관리하세요.

어떻게 삭제하나요?

보호자 PIN 확인 후 Drafts를 열고 Discard draft(초안 버리기)를 선택한 다음 확인하세요. 해당 초안과 그 사진 사본은 삭제되지만 저장된 과제, 보상, 원본 사진, 백업은 삭제되지 않습니다. 저장된 과제와 보상 기록의 개별 삭제는 제공하지 않습니다. ‘앱 삭제’는 설치된 앱의 데이터를 제거하지만 ‘앱 정리하기’는 유지할 수 있습니다. 어느 방법도 Keychain PIN 인증 정보의 초기화를 보장하지 않습니다.

보호자와 아이의 자료는 안전한가요?

6자리 보호자 PIN이 과제 설정, 검토, 규칙 변경을 보호합니다. 포그라운드를 벗어나거나 아이의 과제에 들어가면 세션이 잠깁니다. 기기 암호나 Apple의 가족 승인을 대신하지는 않습니다.

보호자 PIN을 잊었습니다. 지원팀이 재설정할 수 있나요?

아니요. 온라인 계정, 잊어버린 PIN 복구, 원격 재설정은 없습니다. 지원 담당자는 PIN을 조회·재설정하거나 기기에만 있는 기록을 복원할 수 없습니다. 앱을 다시 설치해도 Keychain 인증 정보가 남을 수 있습니다.

현재 PIN을 알고 있을 때 어떻게 변경하나요?

Family → Change parent PIN을 여세요. 현재 PIN을 입력한 다음 새 6자리 PIN을 두 번 입력하세요. 보호자 세션의 잠금이 해제되어 있어도 이 확인은 생략되지 않습니다. 잘못된 입력에는 로그인과 같은 대기 시간이 적용됩니다. 변경에 성공하면 새 PIN으로 보호자 모드에 들어가세요.

작성 중이던 과제는 어디에 있나요?

PIN 확인 후 Drafts를 열어 이어서 작성하거나 버릴 수 있습니다. 초안에는 과제 입력, 정답, 음악 항목, 가져온 사진이나 인식된 문자가 기기에 저장됩니다. 초안에는 보상이 주어지지 않습니다. 가져오기가 중단됐다면 사진을 다시 선택하거나 미완료 가져오기를 취소하세요. 과제 저장 시 초안 삭제를 시도하지만, 정리에 실패하면 파일이 남을 수 있습니다. 초안 원격 동기화는 없습니다.

앱 요금은 어떻게 결제하나요?

다운로드와 단어 과제의 전체 이용 과정은 무료입니다. 비소모성 일회성 구입 한 번으로 다른 과제 유형을 잠금 해제할 수 있습니다. 설정된 미국 가격은 US$3.99이며 실제 지역별 가격은 Apple이 표시합니다. 구독이나 자동 갱신은 없습니다. 구입에 사용한 Apple 계정으로 Restore purchases(구입 복원)를 이용하세요.
