01 · 적용 범위

이 정책은 로컬 웹 미리보기와 iPhone / iPad 개발 버전에 적용됩니다. 사진 가져오기, 기기 내 문자 인식, 개발 중 운동 카운터, 로컬 StoreKit 구매 테스트를 포함합니다. 실제 기능은 버전에 따라 다르며 원격 동기화, 클라우드 인식 및 정식 스토어 상품은 활성화되지 않았습니다.

보호자가 과제를 설정합니다. 현재 온라인 가족 계정이나 원격 신원 확인은 없습니다. 실제 로컬 데이터를 사용하는 버전에서는 보호자 작업에 6자리 PIN이 필요합니다. 별도로 표시된 웹 데모는 가상 기록을 사용하며 PIN 없이 역할을 전환할 수 있습니다. 실제 가족 데이터를 보호하는 용도가 아닙니다.

02 · 보호자 PIN과 기기 내 접근

처음에 보호자가 6자리 숫자 PIN을 설정합니다. PIN 원문 대신 무작위 32바이트 솔트와 PBKDF2-SHA256(210,000회)으로 파생한 32바이트 검증값을 저장합니다. 실패 횟수와 대기 종료 시각도 저장합니다. 이는 기기 내 보호자 접근을 확인하고 반복 추측을 늦추는 데만 사용하며 개발자 서버에 전송하지 않습니다.

iPhone 및 iPad에서는 자격 정보를 시스템 키체인에 WhenUnlockedThisDeviceOnly 보호로 저장합니다. 웹 미리보기는 이 사이트의 localStorage에 저장하므로 보호 수준은 브라우저와 기기 보안에 따릅니다. 웹 미리보기는 안전한 기기 관리 경계가 아닙니다. 사이트 저장소를 확인하거나 지울 수 있는 사람은 로컬 기록을 변경하거나 제거할 수 있습니다.

인증 후 보호자 세션은 메모리에만 있으며 최대 5분간 유지됩니다. 앱이나 페이지가 백그라운드로 이동하거나, 아이의 과제를 열거나, 다시 시작하면 재인증해야 합니다. 다섯 번째 실패부터 최소 60초 기다려야 하며 계속 실패하면 최대 15분까지 늘어납니다. 인증에 성공하면 실패 횟수를 초기화합니다.

보호자가 혼자 초기 설정을 완료하고 기기 암호와 다른 PIN을 보관해야 합니다. 현재 PIN 변경·재설정·복구, 온라인 계정, 클라우드 PIN 동기화 기능이 없습니다. 지원 담당자는 PIN을 확인하거나 원격으로 재설정할 수 없습니다. 앱을 삭제한 뒤에도 키체인 기록이 남을 수 있으므로 재설치가 PIN 재설정을 보장하지 않습니다. PIN은 기기 암호나 Apple 가족 승인을 대신하지 않습니다.

04 · 이용 및 공유

현재 코드는 과제 자료를 개발자 서버로 보내지 않습니다. 원격 가족 동기화가 없으며 광고업체, 데이터 중개업체, 제3자 분석 플랫폼에 공유하지 않습니다. 아이의 정보를 판매하지 않습니다.

기기에만 저장해도 개인정보가 포함될 수 있습니다. 호칭, 숙제, 자유 입력은 개인을 식별할 수 있습니다. 별명을 사용하고 과제에 필요한 내용만 넣어 주세요. 서버 전송이 없다고 기기에 개인정보가 없다는 뜻은 아닙니다.

05 · 시스템 권한과 파일

네이티브는 Apple Family Controls, Managed Settings, Device Activity로 보호자 승인과 선택한 콘텐츠의 관리를 요청합니다. 불투명 토큰을 사용하고 전체 방문 기록이나 연락처를 읽지 않으며 정확한 위치를 요청하지 않습니다. 시스템 처리는 Apple 규칙을 따르고 실제 관리 능력은 승인과 버전에 따라 다릅니다.

웹 파일 추가는 사용자가 선택한 파일을 기기의 브라우저에 저장하며 당사 서버 업로드가 아닙니다. 개인 iCloud 등에서 선택하면 다운로드는 해당 서비스와 사용자 행동에 따릅니다. 선택을 거부해도 다른 파일을 자동으로 가져오지 않습니다.

부모는 학습지, 글, 단어, 악보를 촬영하거나 선택하고 직접 입력할 수도 있습니다. 사진과 인식한 글자는 과제 작성, 제한된 단순 계산 확인 또는 부모 검토에 사용되며 현재 기기에 보관됩니다. 네이티브 개발 버전은 사진과 TXT / CSV를 지원하며 웹 첨부 형식과 다릅니다. 개발자 서버에 사진을 업로드하지 않습니다. 원본에 촬영 메타데이터가 포함될 수 있습니다.

06 · 낭독·운동·악기 연습

운동 화면은 사용자가 카메라를 시작한 후에만 처리합니다. 개발 로직은 스쿼트, 팔굽혀펴기, 윗몸 일으키기를 지원하지만 정확도는 검증 전입니다. 자세 평가, 얼굴 또는 신원 인식, 줄이 통과했는지 증명하지 않습니다. 화면은 기기에서 잠시 처리하며 녹화, 저장, 업로드하지 않습니다. 관절 위치와 횟수로 실시간 안내하며 제출한 추정 횟수는 로컬 과제 기록에 저장할 수 있고 부모 확인이 필요합니다. 일시 정지, 화면 종료 또는 앱이 백그라운드로 전환되면 카메라가 멈춥니다.

연습 타이머를 사용하는 악기 과제의 경우 네이티브 개발 버전은 악기, 곡, 구간 또는 마디, 목표 시간, 반복 횟수, 템포(BPM), 작성한 조건과 누적 연습 시간을 기기에 저장합니다. 연습 화면이 전면에 있고 타이머가 실행 중일 때만 누적합니다. 화면을 벗어나거나 기기를 잠그거나 백그라운드로 이동하면 일시 정지하며 저장된 누적 시간은 기기에 남습니다. 다시 시작해도 자리를 비운 시간은 추가하지 않습니다. 보호자가 재시도를 요청하면 해당 과제의 연습 시간은 0부터 다시 시작합니다. 이 기록은 실제 연주를 증명하지 않습니다. 연주, 반복 횟수, 템포와 완료 여부는 보호자가 확인합니다. 앱은 마이크를 사용하거나 녹음하지 않으며 낭독 또는 연주를 자동 평가하지 않습니다.

07 · 보유 기간·백업·보호

설정, 기록, 첨부는 해당 저장소를 지울 때까지 유지됩니다. 현재 과제별 또는 만료에 따른 자동 삭제는 없습니다. 보상이 만료되어도 기록은 삭제되지 않습니다. 네이티브는 iOS 파일 보호를 사용하며 웹 보호는 브라우저와 기기 보안에 따릅니다.

개발자 운영 클라우드 백업은 없습니다. Apple 기기 백업, iCloud, 시스템 진단 또는 브라우저 백업이 설정에 따라 사본을 보관할 수 있습니다. 네이티브 데이터는 시스템 백업에서 명시적으로 제외하지 않았습니다. 백업, 원본, 내보낸 사본은 별도 관리해야 합니다.

보호자 자격 정보는 과제 파일과 별도로 저장됩니다. 네이티브 키체인 데이터는 앱 삭제 후에도 남을 수 있으며, 현재 자격 정보 삭제·복구 화면이 없습니다. 웹 미리보기의 사이트 데이터를 지우면 해당 PIN 정보와 과제 저장소가 제거됩니다. 키체인 보호는 이 기기에 연결되어 있지만, 앱 삭제가 시스템의 모든 사본 삭제를 보장한다는 뜻은 아닙니다.

08 · 열람·내보내기·삭제·승인 철회

사용 버전의 과제, 기록, 설정 화면에서 정보를 볼 수 있습니다. 웹 내보내기는 정답을 포함하지만 첨부 원본은 포함하지 않습니다. 네이티브의 전체 내보내기나 개별 삭제는 미구현입니다.

웹: 사이트 데이터를 지우면 로컬 기록, 첨부 파일, PIN 정보가 삭제되며 앱에서 복구할 수 없습니다. 네이티브: “앱 삭제”는 설치된 앱 데이터를 제거하고 “앱 정리하기”는 데이터를 남길 수 있습니다. 어느 쪽도 키체인 자격 정보 재설정을 보장하지 않습니다. 현재 PIN 재설정 또는 자격 정보 전체 삭제 기능이 없습니다. 백업, 원본, 수동 내보내기 사본은 별도로 관리하세요.

보호자는 시스템 스크린 타임/가족 관리 설정에서 철회 가능한 승인을 관리하거나 철회할 수 있습니다. 방법은 OS와 승인 유형에 따라 다릅니다. 권한 철회와 기록 삭제는 별개이며 당사는 기기에만 있는 정보를 원격 열람·수정·삭제할 수 없습니다.

09 · 아동과 보호자

가족의 과제와 내용은 부모 또는 보호자가 결정합니다. 현재 아이에게 실명, 신분증, 이메일, 전화번호, 정확한 위치를 요구하지 않습니다. 공개 아동 프로필, 공개 게시, 낯선 사람과의 채팅은 없습니다.

아동 관련 지원 요청은 보호자가 해야 합니다. 필요성과 적절한 승인 없이 얼굴, 목소리, 학교, 주소, 전체 숙제를 보내지 마세요. 잘못 보낸 아동 정보는 보호자가 운영자에게 처리를 요청할 수 있습니다.

10 · 지원에 직접 연락하는 경우

직접 이메일을 보내면 이메일 주소, 요청 내용과 선택한 첨부를 받으며 답변, 조사 및 관련 법적 의무에만 사용합니다. 과제나 아이의 자료를 자동 첨부하지 않습니다.

요청 처리, 필요한 후속 소통과 적용 법적 의무에 필요한 기간만 보관합니다. 아래 이메일로 당사가 가진 지원 자료의 열람, 정정, 삭제를 요청할 수 있습니다. 이메일은 Gmail 서비스로 Google 개인정보처리방침을 따릅니다. 기기에만 있는 기록은 원격 삭제할 수 없습니다.
